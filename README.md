# Sort Numbers in Descending Order

## Explanation

This program arranges a list of numbers from the largest value to the smallest value.

## Problem Statement

Write a Python program to sort a list of numbers in descending order.

## Features

* Accepts multiple numbers
* Sorts values from largest to smallest
* Displays the sorted list

## How It Works

The `sorted()` function is used with `reverse=True` to arrange the numbers in descending order.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `map()`
* `sorted()`

## Program Flow

1. Read numbers
2. Convert them into integers
3. Sort in descending order
4. Display the result

## Sample Input

```text
15 42 8 30 25
```

## Sample Output

```text
Descending order: [42, 30, 25, 15, 8]
```

## Time Complexity

O(n log n)

## Space Complexity

O(n)
